1. Overview

Eleone ("the bot", "we", "us") is a Discord music bot. This policy covers two surfaces: the bot itself, which runs inside Discord servers ("guilds") you invite it to, and this website, which is a static set of informational pages. We collect only what's needed to run playback, premium access, and the saved-content features (playlists, favorites, Spotify connections) that you explicitly use.

2. Data we collect

  • Discord identifiers: your user ID, and the guild/channel IDs where you run commands. We do not read message content outside of the commands you send to the bot.
  • Command usage: the command name and arguments you provide (e.g. a song query, a playlist name) so we can act on it.
  • Music data you save: favorites, cloud playlists, and playlist names/track references you create with the bot.
  • Premium status: vote timestamps (top.gg), redeemed token records, and guild-level premium expiry.
  • Spotify connection data: if you run spconnect, the Spotify profile/playlist references needed to list and play your playlists. We do not store your Spotify password — authentication happens through Spotify's own flow.
  • Guild configuration: custom prefix, locked music channel, and similar settings a server admin sets.

3. How we use it

Data is used strictly to operate the features you invoke: resolving and queuing tracks, enforcing premium/vote gates, remembering your playlists and favorites between sessions, and keeping per-guild settings consistent. We do not sell data, and we do not use it for advertising.

4. Where it's stored

Bot data is stored in a Supabase-hosted database. Access is restricted to the bot's runtime and its operators. We recommend rotating database and API keys periodically, as noted on the Deploy & Support page, if you're self-hosting this project.

5. Third-party services

  • Discord: the bot operates entirely within Discord's platform and is subject to Discord's Privacy Policy.
  • Lavalink: an audio-resolution/streaming node the bot uses to search and play tracks. It processes track requests but is not used to identify you personally.
  • Spotify Web API: used only for accounts that explicitly run spconnect, governed by Spotify's own privacy terms.
  • Top.gg: used to verify votes for the free vote-premium tier.

6. Website storage & cookies

This website sets no tracking cookies and loads no analytics or advertising scripts. The only client-side storage it uses is your light/dark theme preference, saved in your browser's localStorage under the key eleone-theme, purely so the site remembers your choice on your next visit. It never leaves your device.

7. Retention & deletion

We keep data for as long as it's useful to the feature it supports — for example, a playlist stays until you delete it with playlist delete. To request removal of your data from the bot's database, reach out through the contact details below; we'll confirm once it's been deleted.

8. Children's privacy

Eleone is intended for use in accordance with Discord's Terms of Service, which set a minimum age for using Discord itself. We don't knowingly collect data from users below that age threshold.

9. Changes to this policy

If this policy changes materially, we'll update the "Last updated" date at the top of this page. Continued use of the bot or website after a change means you accept the revised policy.
